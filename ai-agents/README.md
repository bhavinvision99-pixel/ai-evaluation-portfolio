# AI agents and applied LLM systems

I have built and tested LLM-based systems across healthcare, research and information services.

My work includes defining system behaviour and requirements, structuring workflows, connecting APIs, testing outputs, diagnosing failures, directing changes and deploying working systems.

## Development approach

I use **Claude Code and OpenAI Codex** extensively. Most Python and JavaScript/TypeScript used in these projects was generated by AI coding agents.

Tools include:

- Claude Code
- OpenAI Codex
- ElevenLabs
- APIs
- GitHub
- Vercel

### School attendance voice-agent concept

Designed a system concept in which a school register could trigger a voice call to an approved parent contact when a child was recorded absent, with the response recorded and transcribed for the school.

This is included as a system-design project. It should not be read as evidence of a completed deployment unless deployment evidence is added later.
