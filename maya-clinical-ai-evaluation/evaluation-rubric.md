# Evaluation rubric

The evaluation used **18 criteria**.

Fourteen came from the platform's built-in evaluation set. During review I identified four gaps and added criteria covering:

1. Atropine and red-light handling
2. NHS-funding honesty
3. Booking mechanics
4. Avoiding inappropriate overselling in low-risk cases

The criteria were grouped around the following areas.

## Clinical accuracy

- treatment efficacy
- realistic expectations
- lifestyle advice
- risk-appropriate recommendations

## Safety and triage

The evaluation included **2 safety-gate criteria** covering red flags and recent blur.

Failure on either safety gate failed the whole call.

## Guardrails

The agent was expected to:

- avoid diagnosis
- avoid invented facts
- handle atropine/red-light questions within defined boundaries
- describe NHS funding accurately

## Conversation and process

Testing also considered:

- tone and empathy
- intake behaviour
- booking behaviour
- data capture
- handling of tool failure

## Note on source material

This repository does not reproduce the platform's proprietary built-in rubric verbatim. The categories above document the evaluation structure and the four gaps introduced during this review.
