# Atropine licensing finding

A review found that several knowledge-base files still described low-dose atropine as unlicensed or specialist-only after Ryjunea received UK licensing in November 2025.

The source material was corrected across **four files** so the agent could state that atropine is licensed, is not currently offered by the practice, and that availability questions should be directed to the optometrist.

This finding is documented as **WE-01** in the evaluation workbook.
