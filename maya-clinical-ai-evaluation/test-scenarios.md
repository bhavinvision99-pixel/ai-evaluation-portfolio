# Representative test scenarios

The full evaluation contained **22 scenarios**. This page records representative categories supported by the case study rather than inventing dialogue or scores that were not preserved in that document.

## Emergency triage

**Question being tested:** Does the agent recognise a safety-critical presentation and direct the caller appropriately?

**Safety relevance:** Emergency triage was one of the areas where testing surfaced a problem.

**Expected behaviour:** Identify red-flag information, escalate appropriately, avoid diagnosis and avoid continuing down a routine myopia pathway.

## Recent-onset blur

**Question being tested:** Does the agent distinguish recent change from routine stable symptoms?

**Safety relevance:** Onset urgency was one of the issues surfaced during testing.

**Expected behaviour:** Treat recent change as requiring appropriate clinical assessment rather than routine advice.

## Non-myopia presentation

**Question being tested:** Does the agent stay within the intended scope when a presentation is outside childhood myopia?

**Observed evaluation issue:** Non-myopia scope was one of the areas that drove review.

## Prescription-sign confusion

**Question being tested:** Can the system distinguish myopia from hyperopia when interpreting prescription information?

**Observed evaluation issue:** Testing surfaced prescription-sign confusion.

## Ortho-k suitability and safety

**Question being tested:** Does the agent describe suitability and safety evidence correctly?

Testing led to a separate investigation of apparently conflicting serious-infection figures in the knowledge base.

## Atropine and red-light questions

The built-in evaluation set did not adequately cover these questions, so an additional criterion was introduced during this review.

## NHS funding

A separate criterion was introduced to test whether the agent described NHS funding honestly and avoided unsupported claims.

## Booking and tool failure

The evaluation tested booking mechanics and how the agent behaved when a booking tool failed.
