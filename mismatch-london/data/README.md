# Data

## Why the CSV files are not included

MISMATCH was developed from public aggregate housing datasets, but the raw and processed CSV files used during analysis are **intentionally not distributed in this portfolio repository**.

The purpose of this repository is to demonstrate the analytical process, methodology, product thinking and outputs without unnecessarily republishing source data.

This also ensures that the original publishers' licensing, attribution and redistribution requirements remain authoritative.

## Data used

The analysis draws on:

- **ONS Census 2021** — occupancy rating (bedrooms) by tenure
- **Greater London Authority** — affordable/social housing delivery datasets
- **MHCLG / Local Authority Housing Statistics** — local-authority housing waiting-list data

See [`sources.md`](sources.md) for further information.

## Reproducibility

The repository documents:

- definitions used
- geographic scope
- transformations
- formulas
- benchmark calculations
- Relative Imbalance methodology
- sensitivity testing
- limitations

This provides an auditable description of how the analysis was produced while leaving source-data acquisition subject to the publishers' original terms.

## Privacy

MISMATCH uses aggregated public housing statistics only.

No tenant-level, household-identifiable, patient-level or personally identifiable information is included in the analysis or repository.
