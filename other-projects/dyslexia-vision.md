# Dyslexia Vision

Live site: https://www.dyslexia.vision/

A public information and tools platform designed around practical problems experienced by people with dyslexia.

## My contribution

- concept and product direction
- information architecture
- behavioural design
- AI-assisted development
- testing and deployment

## Development approach

The project uses AI-assisted software development. Claude Code and Codex are used for implementation, with GitHub/Vercel and APIs used where required.

This project is included as evidence of taking a problem from concept to a working public product.
