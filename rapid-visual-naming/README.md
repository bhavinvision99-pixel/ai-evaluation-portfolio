# Rapid visual naming and scanning assessment

## Problem

This project explores a tablet-based method for measuring rapid visual naming and scanning behaviour.

## My role

I translated a clinical measurement problem into a digital assessment workflow and worked on approaches for capturing timing and performance measures.

Work has included:

- tablet-based assessment
- browser-based approaches
- microphone timing
- anonymised normative data
- parallel UK/US assessment tracks
- practical iteration of the measurement process

## Why it is included

The project is included as an example of translating a measurement question into a working digital system and iterating the method through testing.

Further methodological detail can be added as the project develops.
